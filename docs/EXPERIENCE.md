# 《给谁的伞》：126 秒体验样片

这是 AP 观众心景的原创本地图解样片。用户首次审阅否决了画面与系统配音质量；本目录保留为技术过程证据，不代表审美验收通过。新的完整创作另行制作，故事与形式均可更换。网页不联网发送反馈。

## 已交付内容

- `demo/index.html`：可离线打开的播放器与反馈页。
- `demo/experience.mp4`：实际渲染的 126 秒影片，1280 × 720、24 fps、H.264、AAC 双声道。此文件仅保留本地，公开源码仓库需自行渲染。
- `demo/cover.png`：无揭晓的封面。
- `demo/predictions.json`：制作前保存的方向、时间窗和失误条件。
- `examples/experience-{rough,final,spoiler}.json`：三个可直接交给计算器或 MCP 的作品文档。
- `demo/comparison.json`：同一引擎、参数、观众与目标下的实际比较。
- `demo/render.py`、`speech.ps1`、`narration.json`：原创画面、声音与字幕源码。

影片、旁白、截图与验收运行文件不需要纳入 Git。克隆仓库后，网页发现 MP4 缺失会显示制作入口并保留封面。

## 观看与反馈顺序

1. 0–42 秒：具体情境，暂不向观众命名目标感受。
2. 42 秒：自动暂停，先用自由文字记录注意、想法和感受，再填写可选的分项强度。
3. 49–74 秒：解释三条事先记录的预测及区别。
4. 74 秒：再次暂停，先记录对解释的反应；在此之后影片才提示“怀疑”这个可能。
5. 126 秒结束后：汇总命中和未命中、查看预注册原件，下载本机反馈 JSON。

反馈没有姓名、IP、设备识别码或自动上传。自由文本可能含观看者自行填写的个人信息，分享前应自行检查。可全部留空、跳过、给零分、写无感或不同反应。重看次数另行记录；后续反馈不能冒充首次体验。

MP4 本身是线性文件，只有暂停邀请，没有自动收集功能。网页才提供两次中途暂停。HTML 中的“重看”保留原回答；“清除本机记录”只删除此样片自己的 localStorage 项。

## 本地重建

所需小型依赖：Python 3.10+、Pillow、numpy、FFmpeg、Node.js。Windows 旁白脚本使用系统已安装的 `System.Speech` 中文语音，不调用网络。

```powershell
# 可先查看已安装语音，按需把名称传给 -VoiceName。
powershell -NoProfile -File demo/speech.ps1 -VoiceName "Microsoft Huihui Desktop"
node demo/evaluate.js
python demo/render.py --prepare-audio --render
```

`render.py` 默认使用 Windows 微软雅黑。如果使用其他平台，请通过 `AP_FONT_REGULAR` 和 `AP_FONT_BOLD` 指定已安装且可用于本地渲染的中文字体；字体文件不随仓库再分发。

非 Windows 系统可用自行录制或本地 TTS 生成 `demo/audio/n01.wav` 至 `n12.wav`，文本与时间槽在 `narration.json`。渲染器会读取实际音频时长，用 FFmpeg `atempo` 适配时间槽并记录 `audio-timing.json`；不可以在没有中文语音的情况下宣称已经生成了旁白。

```sh
# 只检查代表帧；不重新合成音频或完整影片。
python demo/render.py --frames-only

# Playwright 可选：验证实际网页流程。
# 若依赖不在默认 node_modules，请设置 PLAYWRIGHT_MODULE。
# 使用已装 Edge 时，可设置 EDGE_EXECUTABLE。
node demo/acceptance.js
```

## 实际版本修改与模型结果

修改前：初稿让空椅保持 20 秒无新内容。修改后：缩为 8 秒，并加入一处可读但不完整的空间伏笔。新内容是实质剪辑变化，系数和评分目标没有调整。

| 版本 | 时长 | 温柔·苦甜目标指数 | 等待段无聊 | 等待段注意 |
|---|---:|---:|---:|---:|
| 初稿长等待 | 138 秒 | 62.82 | 0.350 | 0.810 |
| 实际成片 | 126 秒 | 64.51 | 0.207 | 0.841 |
| 开头提前揭晓 | 126 秒 | 68.58 | 0.117 | 0.660 |

这里的强度不是概率，也不是实测观众反应。提前揭晓可能更早建立关系和理解，所以此评分目标反而给它更高分。保留这一结果，不强迫“有悬念”的版本获胜。成片采用的是在短时体验中可以示范两次解释层递进的方案；不能仅凭它分数上升就宣称更美或理论正确。

首次粗稿中，暗处小猫轮廓过亮，会提前暴露揭晓；代表帧检查发现后降低暗处对比并把位置移到座椅下方。伞柄也移开脸部。此视觉修正服务真实空间可读性，不改评分来掩盖问题。

## 验证与限制

本机成片的 ffprobe 结果：126.000 秒、1280 × 720、24 fps、48 kHz 双声道 AAC；整片解码无错误。音轨 `volumedetect`：平均 −20.1 dB、峰值 −2.5 dB。15 个代表帧已检查文字、遮挡与版式；所有旁白时段自动核对无越界。

本机 Edge 实际验证：13 项通过，包括离线元数据、解释前暂停、自由回答先于命名问卷、怀疑提示前再次暂停、零与未知区分、HTML 惰性渲染、反馈下载、刷新恢复、390 px 页面不横向溢出及零外部 HTTP 请求。第一次测试失败来自测试工具读取收起的 `<details>` 时使用了 `innerText`，改用 `textContent` 后通过；原失败报告保留。后续针对“无 MP4 的源码克隆”另检查了错误提示。

这些是内容检查与运行证据。尚未进行人类观看样本校准，也未对成片进行真实人工听音验收。系统合成语音可能存在节奏和韵律不足；字幕提供完整内容。不能把音频波形检查等同于听感确认。

字幕与后半段术语解释可能造成需求特征；自评仍有回忆偏差；本片受众与文化先验限定明确。这是体验与反馈原型，不是随机对照心理实验，也不是证明 AP 已解释全部心理的材料。

## 原创与隐私

所有图形由本仓库脚本绘制，背景音乐与雨声为程序合成。没有外部素材、网络语音或新模型费用。系统语音渲染文件只作本机演示，不随公共仓库提交。源文件使用相对路径，反馈保留在观看者设备；仓库不存真实用户反馈。
