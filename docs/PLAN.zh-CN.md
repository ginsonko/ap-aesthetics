# AP 观众心景可复用工具与体验演示 · 有界计划

日期 2026-10-05。当前用户授权：在现有计算器基础上制作可调用 Skill/MCP、GitHub 开源仓库、可复现的群体数据校准，以及三分钟以内的解释作品供用户首次观看反馈。继续只在本分支工作，不修改伴生主工程。

## 交付图景

1. 独立开源仓库 `ap-aesthetics`：只复制可发布源码、已授权自制样例、来源说明与公开证据，不复制聊天、绝对私人路径、Key、工作室记录或历史原始论文。
2. 一套引擎：浏览器、CLI、MCP共用已有计算，补版本对比与可追溯薄弱点报告；自动创作通过Skill组织标注→评估→提出不同改法→重算→保留副作用，不以改标注抬高分。
3. 参数/校准独立版本化：接受匿名群体观测，按作品分组切分训练/验证/留出；有限参数搜索和输出校准可插拔；缺测不补零，模型自行预测不能当真人标签。保留未校准基线，只有留出改进才建议采用。
4. 公开数据：先查许可、受试者/评价对象与标签含义，下载适合的公开数据并输出真实统计；无法测到的AP感受不从valence/arousal硬推出来。明确公开大数据、独立输入标注、演示数据三种证据边界。
5. 体验演示：本地原创动画/动态图文，先体验再揭晓，预注册可错的预测；先收观众反应再展示解释，不把抗拒/怀疑/无反应都判为成功。输出可播放短片或交互短片及图片；无需上传私有素材或付费生成。
6. 安装可发现Skill和本地stdio MCP，实际协议烟测、独立调用、冷启动和文档验证；GitHub发布前只对明确发布清单扫秘密与本机信息。

## 多维反向找茬

- 刷分：艺术目标固定；作品版本与标注哈希、参数版本一起保存；报告评分的局限和取舍，不能把高分直接叫满意率。
- 事后解释：先存预测和演示版本；观众可选无感/没注意/不同感受；评分不直接改成用户的反应。
- 标签泄漏：训练、验证、留出按作品/来源分组；统计评估用未参与拟合的标签；公开评论作者情绪不冒充观众体验。
- 标定范围：VAD只能验证VAD接口，不能验证全部47状态；小样本只验证方法，不能冒充大数据准确率。
- 个体/群体：独立画像和分群先验，保留方差；群体也受文化、平台、年代漂移影响。
- 发布安全：新干净仓库、白名单复制、许可清单、无任何凭据或本机日志；用户已明确授权开源，无需重复询问。
- 复用安全：MCP只接受结构化对象/显式本地路径，不自行浏览网络或读取任意系统路径；运行不收费。公开数据下载为显式命令。
- 交付与研究：首版接口、校准管道和演示可交付；真实人群有效性仍由数据检验，不用未知阻塞全部实现。

## 实施与验收

先核对工作室可用伙伴，派适合的独立研究/审阅；主作者唯一整合。开发改动按模块分工不同时写同一文件。实际验证MCP初始化/工具调用、CLI评估/比较、校准泄漏防护与留出报告、Skill入口、浏览器、媒体时长/可读性/声音。必要失败修复；不重跑无关旧切片。最终记录源码与媒体哈希、公开仓库URL、安装状态、公开数据范围、具体未达项及后续最小用户反馈。
